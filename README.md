# HOUP MTA Launcher — Windows native C++

Це нативний Win32 C++ варіант без Qt та без сторонніх runtime-бібліотек.
Інтерфейс використовує Windows API + GDI+ (входить до Windows).

## Функції
- Український інтерфейс, головна та налаштування.
- Логотип HOUP і фонове фото.
- Панель новин-заглушка для майбутніх оголошень.
- Вибір `Multi Theft Auto.exe`, збереження шляху в `HOUP.ini`.
- Кнопка запуску MTA, індикатор підготовки.
- Підсвічування кнопок при наведенні.

## Важливо про готовий EXE
У цьому архіві є вихідний C++ код і всі ресурси, але готовий Windows EXE не був зібраний/перевірений у цьому середовищі.
Для створення `HOUP.exe` потрібен компілятор MSVC (Visual Studio Build Tools) на комп'ютері, де виконується збірка.

### Збірка
1. Відкрий **x64 Native Tools Command Prompt for Visual Studio**.
2. Перейди в папку цього проєкту.
3. Запусти `BUILD_WINDOWS.bat`.
4. Готовий файл з'явиться у `release\HOUP.exe`.

На комп'ютері гравця Visual Studio або Qt не потрібні: це нативний Windows EXE. Поруч із EXE залиш папку `assets`.
Для розповсюдження зручніше запакувати `release` у ZIP.

## Межі поточної версії
Прогрес-бар показує коротку підготовку перед запуском, а не фактичне завантаження оновлень.
Для справжнього патчера потрібні URL сервера оновлень, маніфест файлів, перевірка SHA-256 і механізм безпечного оновлення.
Новини зараз демонстраційний текст у коді.
