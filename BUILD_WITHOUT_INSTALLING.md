# Як отримати готовий HOUP.exe без встановлення програм

Збірка виконується на серверах GitHub у хмарі. На вашому ПК компілятор та Visual Studio не потрібні.

1. Створіть безкоштовний акаунт на https://github.com/, якщо його ще немає.
2. Натисніть **New repository**, задайте назву `HOUP-Launcher` і створіть репозиторій.
3. Завантажте в репозиторій усі файли та папки з цього архіву (включно з прихованою папкою `.github`).
   Важливо: у корені репозиторію мають лежати `main.cpp`, `assets/` та `.github/workflows/build-windows.yml`.
4. Відкрийте вкладку **Actions**. Виберіть **Build HOUP.exe** і натисніть **Run workflow** (якщо збірка ще не стартувала автоматично після завантаження).
5. Дочекайтеся зеленого статусу. Відкрийте завершений запуск і внизу в розділі **Artifacts** завантажте `HOUP-Windows-x64`.
6. Розпакуйте ZIP. Запускайте `HOUP.exe`, не відокремлюючи від нього папку `assets`.

Архів містить вихідний код і автоматичний сценарій збірки. Сам `HOUP.exe` ще не включений: він буде створений GitHub Actions після завантаження проєкту.
